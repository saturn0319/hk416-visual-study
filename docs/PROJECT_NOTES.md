# 项目说明

## 展示定位

本项目用于呈现个人三维外观造型练习，主要讨论整体轮廓、视觉比例、表面材质和作品构图。

## 文档结构

| 位置 | 用途 |
| --- | --- |
| `README.md` | 项目首页与导航 |
| `LICENSE.md` | 原创说明文字的许可范围 |
| `NOTICE.md` | 作品来源、第三方内容与署名说明 |
| `CONTRIBUTING.md` | 展示反馈与文档修改约定 |
| `docs/GITHUB_SETUP.md` | 仓库名称、简介和发布步骤 |
| `.github/ISSUE_TEMPLATE/visual-feedback.yml` | 展示与文档问题反馈 |
| `docs/images/` | 后续外观图片目录，当前尚未创建 |

本地原有工作文件与展示文档共处项目目录。Git 忽略规则采用展示内容白名单：只有约定的文档、反馈模板及静态图片进入常规版本跟踪。

## 当前核实范围

已核对本地目录清单并整理展示文档。未打开原始建模文件，未检查其几何、尺寸、配合、功能或软件兼容性，也没有从模型生成新的图片。

当前未提供静态作品图片，因此 README 不将参考图片或其他人的作品描述为本人的渲染成果。

## 后续展示素材

| 素材 | 内容建议 |
| --- | --- |
| 整体外观 | 清晰显示完整外形，背景简洁 |
| 左右侧面 | 使用一致的视角与光照便于观察外观 |
| 表面材质细节 | 展示外部表面效果与视觉处理 |
| 创作记录 | 说明实际使用的软件版本、创作时间和参考来源 |

图片应保持为外观展示，不包含尺寸标注、剖面或内部功能细节。文件命名建议见 [发布指南](GITHUB_SETUP.md)。

## 维护检查

新增内容后，应检查首页链接、图片路径、署名和许可说明。没有实际完成的工作保留为“待补充”，避免将计划写成既有成果。
